# 仅格式规范化规则

## 用途

当用户要求“统一格式规范优化剧本”“规范剧本格式”“只整理格式”“分镜编号连续”“台词前缀统一”等同义任务时，必须读取本文件。

本模式是“仅格式优化”模式，不得新增、删除、压缩、扩写、重排、改写、解释或优化原有剧情内容。

## 最高优先级规则

只规范格式，不改剧情。

禁止：

- 不得新增剧情节点。
- 不得删除剧情节点。
- 不得合并或拆分剧情事件，除非用户明确要求。
- 不得改写台词含义。
- 不得额外添加原文没有或用户没有确认的人物情绪。
- 不得改变人物关系、场景顺序、剧情因果、冲突结果、悬念或结局。
- 不得以“优化戏剧性”为理由改动原文内容。

如果格式规范时需要判断缺失的情绪、说话人、场次、时段、景别、机位、运镜、微表情或体态，而原文没有可安全搬运的信息，必须用弹窗给出合理化建议让用户决定，或在机械格式化时标注为“待确认”，不得编造。

## 分镜编号规则

所有分镜必须从阿拉伯数字 `1` 开始连续编号：

```text
1.
2.
3.
```

除非用户明确要求按场次重新编号，否则不得每场重新从 1 开始；不得用中文数字或混合编号作为主分镜序号。

## 固定分镜字段头

每组分镜必须固定标注：

```text
（场次：时段 | 场景参考图 | 景别，机位 | 镜头运镜 | 自然微表情 | 自然体态 |）
```

规则：

1. 必须保留全角括号、竖线和字段顺序。
2. 如果原文已有对应信息，只能搬运到对应字段，不改变含义。
3. 如果原文缺失且不能安全推断，填“待确认”或弹窗询问。
4. 不得新增原文没有的视觉内容、镜头内容、表演细节、微表情或体态动作。

## 人物台词前缀规则

人物开口说出的台词前必须统一添加：

```text
（人物情绪）（开口说道）
```

执行规则：

- 如果原文明确写了情绪，用原文情绪替换“人物情绪”。
- 如果原文没有明确情绪，且用户只要求机械格式化，使用“情绪待确认”，不得编造。
- 前缀后保留原始台词正文，不改台词含义。

示例：

```text
（愤怒）（开口说道）你怎么能这样？
```

## 内心独白前缀规则

内心独白统一标注为：

```text
（人物情绪）（内心独白os）
```

只用于原文明确属于内心独白 / OS / 心声 / 内心想法的内容。不得把开口台词改成内心独白。

## 画外音前缀规则

画外音统一标注为：

```text
（人物情绪）（画外音vo）
```

只用于原文明确属于画外音 / VO / 旁白的内容。不得把内心独白改成画外音，除非用户确认。

## 输出合同

完成仅格式规范化后，必须说明：只规范了格式，没有故意增减原有剧情内容。

推荐输出：

```text
格式规范说明：
- 分镜已从 1 开始连续编号。
- 每组分镜已统一为固定字段头。
- 人物台词 / 内心独白 / 画外音已统一前缀。
- 未增减原有剧情内容。

规范后文本：
...
```

## QC 失败码

- `FAIL_FORMAT_SHOT_NUMBERING`：分镜没有从 1 开始连续编号。
- `FAIL_FORMAT_SHOT_HEADER`：分镜字段头不符合固定格式。
- `FAIL_FORMAT_DIALOGUE_PREFIX`：人物台词缺少 `（人物情绪）（开口说道）`。
- `FAIL_FORMAT_OS_PREFIX`：内心独白缺少 `（人物情绪）（内心独白os）`。
- `FAIL_FORMAT_VO_PREFIX`：画外音缺少 `（人物情绪）（画外音vo）`。
- `FAIL_FORMAT_CONTENT_CHANGED`：仅格式规范化过程中增删或改变了剧情、台词含义、场景顺序或人物动作。
